# ClearShare Technologies — website

Static site for clearsharetechnologies.com. No build step: Vercel serves this folder as-is.

- `index.html` — the site (single file)
- `manifest.webmanifest`, `icon-*.png`, `favicon.png` — app icons / add-to-home-screen
- `qr.png` — QR code (regenerate to point at https://clearsharetechnologies.com once DNS is live)
- `vercel.json` — clean URLs and security headers

## Deploy
Connected to Vercel: every push to `main` deploys to production.

## Status
Prototype with synthetic data. "ClearShare Technologies" is a working name; trademark and legal review pending.
